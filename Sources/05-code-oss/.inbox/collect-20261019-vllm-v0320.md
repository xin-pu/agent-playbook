## E1 · vLLM v0.32.0：systemone 端点、通用 hf parser 与低精度 KV cache 铺开

- 获取日期：2026-10-19
- 来源 URL：<https://github.com/vllm-project/vllm/releases/tag/v0.32.0>
- 本地原件：—
- 适用范围：官方 release notes（2026-10-18T06:50Z 发布），覆盖该版本 API 面与特性变化；吞吐/内存数字为官方 PR 基准口径，未经独立复现。
- 证据等级：A
- 可提炼要点：
  1. 规模：814 commits、363 位贡献者（其中 121 新）（release notes）。
  2. 新 `POST /v1/systemone` 端点：对结构化状态回答 `choice` / `noul` / `score` 类问题并默认启用，属 API 面扩展，值得进「new API」跟踪线（release notes，PR #59299/#60677）。
  3. 新增 `hf` tool/reasoning parser（`--tool-call-parser hf`、`--reasoning-parser hf`）：直接读 checkpoint 的 `response_template`，随模板发布的模型不再需要 model-specific parser，Python 与 Rust 前端同支持（PR #58604/#59005）。
  4. 低精度 KV cache 扩面：NVFP4 KV cache 落到 SM8x/SM12x/SM90；GLM-5.x 在 SM100 默认 FP8 KV cache，官方基准口径为吞吐 +2.3~5.5%、TTFT 代价 +7~11%（数字出自 release notes 引用 PR，未独立复现）。
  5. Model Runner V2 新增 GPU n-gram 投机解码（变长草稿）并在 ROCm 上成为默认（release notes）。
- 关闭条件：需确认 `POST /v1/systemone` 是否进入稳定 API 文档还是实验端点；官方文档站点登记后可关。
