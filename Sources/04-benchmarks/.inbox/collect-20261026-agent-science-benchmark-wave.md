## E1 · PHYRD：理论物理「复现 + 发现」活基准

- 获取日期：2026-10-26
- 来源 URL：<https://arxiv.org/abs/2610.32575>
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖理论物理推导复现（63 题）与修改条件后的推论发现（43 题），子问级 rubric 评分；不覆盖实验物理与数值仿真任务。
- 证据等级：A
- 可提炼要点：
  1. 原文口径：五个模型 Reproduce 全题准确率 49.21%~68.25%，闭卷 Discover 18.60%~74.42%；配工具后四个模型 Discover 完成更多但概念错误与缺论证持续存在（预印本数据，未复现）。
  2. FormulaForest 合成数据迁移有效：在 OpenAI 的 FrontierScience 基准上把 Qwen-35B-A3B 准确率从 61% 提到 72%（原文口径）。
  3. 「living benchmark」形态：题目随文献演进追加，与既有基准完整性主题相关。
- 关闭条件：未核对题目集版本冻结机制与污染防控；引用 61%→72% 需注明未复现。

## E2 · SCI-AGENT-EXAM：120 题跨 11 学科的科研 workflows 考试

- 获取日期：2026-10-26
- 来源 URL：<https://arxiv.org/abs/2610.32441>
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖 11 个学科、7 类科研任务（SWTT 分类法）的专家策划任务，要求可执行产物 + 文本产物双输出；不覆盖同行评审级科研闭环。
- 证据等级：A
- 可提炼要点：
  1. 混合评测协议：可执行产物用确定性程序化验证，文本产物用裁判评估——对应异构输出的分轨打分设计。
  2. 120 题全部专家策划，规模小于常见 coding agent 基准，主打任务类型覆盖面而非题量。
  3. 与既有 agent-benchmarks 箱同层次，合箱时追加。
- 关闭条件：摘要未给出各模型成绩数值；需原件或官方 leaderboard 才能作横向比较。

## E3 · Async-RBench：异步任务执行的「结果处理」评测

- 获取日期：2026-10-26
- 来源 URL：<https://arxiv.org/abs/2610.32429>
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖主 agent 与子代理并行时结果到达的处理质量（更新/保留/避免/重验四类约束）；不覆盖最终任务正确率之外的通用多代理协作。
- 证据等级：A
- 可提炼要点：
  1. 问题定位：只看最终成功无法揭示异步结果是否被正确处理，自然到达时序又不可复现——用 scenario controller regulated 投递来可控重放。
  2. Event Response Contract（ERC）把每个响应须「改什么、留什么、避什么、重验什么」写成契约；Dynamic Replanning Score 将响应过程与结果等权。
  3. 200 个可执行任务、8 个场景（原文口径）。ERC 与 02-agent 箱 tool-selection-policy-enforcement 主题在「契约化约束」上同构，跨箱引用即可。
- 关闭条件：摘要未含成绩分布；需原件核对 DRS 评分实现与可复现性。

## E4 · IGG：可见性约束下的交互式 GUI grounding

- 获取日期：2026-10-26
- 来源 URL：<https://arxiv.org/abs/2610.32536>
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖目标不可直接可见时需先交互使其显形再点击的 GUI grounding（601 任务、16 环境、7 类可见性约束）；不覆盖自由文本输入类 GUI 任务。
- 证据等级：A
- 可提炼要点：
  1. 指出现有静态截图式 grounding 基准的系统盲区：离屏、悬停才出现、遮挡、延迟可操作等「reveal step」未被评测。
  2. 原文口径：人类 94.6%，GPT-5.5 79.4%，最强开源 VLM 仅 31.6%（预印本数据，未复现）。
  3. 动作空间刻意收敛为 scroll/move/drag/wait/click 五种，把「恢复可见性」与「定位」分离评测。
- 关闭条件：未核对七个子类型的分项成绩；引用开源/闭源差距须注明单次评测未复现。

## E5 · NTBench：近似合法答案的 near-target 提示注入

- 获取日期：2026-10-26
- 来源 URL：<https://arxiv.org/abs/2610.32531>
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖「保留大部分合法输出、仅注入错误/有害改动」的 near-target 提示注入评测，含响应轨与 agent 工具调用轨；不覆盖完全抛弃用户请求的显式越狱。
- 证据等级：A
- 可提炼要点：
  1. 方法论点：现有注入基准可通过拒绝「明显偏离用户请求」的攻击刷高分，掩盖对微调型攻击的脆弱性——测无关指令并不能暴露该弱点。
  2. NTBench 以既有数据集合法任务为底，由参考结果反向生成 target-instruction 对，双轨（错误化 / 有害化）分别评测。
  3. 与既有 benchmark-integrity 与 agent-safety 主题同层，合箱时引用而非复述。
- 关闭条件：摘要截断处未见模型成绩（'Ha…'）；需原件补齐主要结论数值。
