# 投递：程序性理解与结构生物学两类领域基准

## E1 · StepBench：用 wikiHow 流程诊断 agent 的程序性理解

- 获取日期：2026-10-21
- 来源 URL：https://arxiv.org/abs/2610.26679
- 本地原件：`Sources/04-benchmarks/.inbox/originals/arxiv-2610.26679-stepbench.pdf`
- 适用范围：preprint，未经同行评议（UCL AI Centre + Microsoft + Cohere Labs 等，v1 提交 2026-10-19）；覆盖开放域（含 cyber-physical 背景）任务分解、步骤排序与缺口识别的诊断性评测；不覆盖端到端执行型机器人任务验证——开放域流程难以执行验证正是其立题动机。
- 证据等级：A
- 可提炼要点：
  1. 构成：StepBench 含 5 类任务，源自 6,885 条人工整理的 wikiHow 流程、覆盖 81 个类别；同一批流程复用于不同任务，使「分解 / 时序依赖 / 缺口识别」等能力可直接横向比较。
  2. 定位差异：区别于只生成任务分解或只预测步间依赖的既有规划基准，StepBench 以诊断性子任务刻画强弱项，并检验这些子能力与端到端计划生成性能的相关性。
  3. 动机可核对：开放域任务无法像代码/沙盒任务那样靠执行验证计划，因此流程理解需要独立基准——与 `04-benchmarks` 既有「工具层固定作为控制变量」的证据互补。
- 关闭条件：需补读正文得到各模型分项分数（本轮只提取摘要与前 3 页）；正式发布版本或第三方 leaderboard 收录后可关。

## E2 · ProteinGeoBench：分数里有多少是模型能力、多少是评测配置

- 获取日期：2026-10-21
- 来源 URL：https://arxiv.org/abs/2610.26829
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖蛋白质结构任务上 agent 评测的统计解读——131 个任务、4 个前沿模型 4,249 次 rollout、另 26 个模型 4,486 次试验；不覆盖分子生物学结论本身，讨论对象是评测方法学。
- 证据等级：A
- 可提炼要点：
  1. 前沿模型区分度有限：4 个前沿模型中 3 个分数落在 0.785-0.816 区间、相互差距小于 0.031 且置信区间不分离，第 4 个为 0.707（与前三个差距显著）。
  2. 能力画像：多数前沿模型「查结构元数据」强于「由坐标算几何」；数值类任务仅 28/131，却占四模型全失败 12 题的一半——分数构成远比总分 informative。
  3. 评测配置敏感：每任务只跑 1 次时，23.9% 的 bootstrap 重采样会把不同模型排第一；换成模型自带 CLI agent，分数漂移 -0.071 到 +0.086，作者自认样本不足以排除中等 harness 效应——为「报告须附任务族分解、rollout 数、harness 与网络访问条件」提供了定量依据。
  4. 注意其自我限制声明：各实验用了不同任务子集，无法把模型 / harness / 访问权限 / 任务构成四因素互相排序。
- 关闭条件：作者若能给出统一子集上的四因素对照实验，或第三方按该清单重跑，可关闭「配置敏感性未分离」的问题。
