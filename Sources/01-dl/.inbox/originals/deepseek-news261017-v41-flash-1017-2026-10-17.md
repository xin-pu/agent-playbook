DeepSeek-V4.1-Flash-1017 发布 2026/10/17

DeepSeek V4.1 Flash 现已更新至 V4.1-Flash-1017 版本，官方网页端、APP 与 API 模型已同步变更为新模型。

性能–费用的帕累托改进：相比上一版本的 DeepSeek V4.1 Flash，新模型在各方面的基准测试中取得了长足的提升。在提升性能的同时，还缩短了模型的任务运行时间与输出长度，让用户以更低成本、更快速度完成任务，在多个 Harness 下达到了新的性能-费用帕累托最优。本次着重针对 DeepSeek Harness、腾讯 CodeBuddy、WorkBuddy 等平台框架进行了优化，建议升级到 DeepSeek Harness 0.2.1-rc.1 及以上版本。图注：DeepSeek V4.1 Flash 1017 使用 mini-swe-v2 框架测试 DeepSWE 的性能/成本图。

从零开始的完整项目开发：V4.1 Flash 1017 通过基于自反馈的强化学习（RL）训练技术，提升了在游戏开发、3D 建模等方面从零开始构建完整项目的能力，支持更多"许愿式"编程任务及项目开发请求。案例：故宫 3D 建模、网页版赛车游戏、基于 godot 引擎的《传送门 2》复刻、Valley of Ages（3D 场景展现史前到现代）。

开放自研搜索 API：DeepSeek 网页端与 API 端的搜索能力由自研 DeepSeek 搜索引擎提供底层支持，稳定处理每天来自全球各地的数亿次搜索请求。DeepSeek 搜索是 AI 原生的通用搜索引擎，索引了全球千亿级网页，支持多语言搜索，实时返回高相关、高权威、高时效结果；针对 SEO 作弊、GEO 操纵和低质 AIGC 有识别过滤机制。本次新版本发布 DeepSeek API 新增对 Search 与 Fetch 接口的支持，能力正式向公众开放，两个接口价格均为 5 元/千次。当前用户在 DeepSeek Harness / Claude Code / Codex 中使用 DeepSeek API 时，已通过 Server 端工具调用访问 Search/Fetch 接口，这部分调用目前未计费，将于北京时间 2026 年 11 月 1 日 00:00 开始按次收费。

模型开源：DeepSeek-V4.1-Flash-1017 权重地址——HuggingFace 仓 `deepseek-ai/DeepSeek-V4.1-Flash-1017`；ModelScope 仓 `deepseek-ai/DeepSeek-V4.1-Flash-1017`。
