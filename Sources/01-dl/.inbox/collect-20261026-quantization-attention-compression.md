## E1 · BiLoCo：FP4 量化的二值低秩修正

- 获取日期：2026-10-26
- 来源 URL：<https://arxiv.org/abs/2610.32243>
- 本地原件：`Sources/01-dl/.inbox/originals/arxiv-2610.32243-biloco-binary-lowrank-quant.pdf`
- 适用范围：preprint，未经同行评议；覆盖 4B~72B LLM 的 FP4 PTQ 与低秩修正（Blackwell 原生 FP4 tensor core 背景）；不覆盖整型量化训练期方案与非 LLM 架构。
- 证据等级：A
- 可提炼要点：
  1. 针对 SVDQuant 的痛点：BF16 低秩修正每秩位宽高，且与主 FP4 GEMM 抢同一批 tensor core；BiLoCo 把左右因子存成 {±1} 二值符号向量，每个 rank-one 分量存储降 16 倍，修正退化为加减法、可跑在 CUDA core 上与主 GEMM 并发。
  2. 原文实验口径：4B~72B 五个模型上，WikiText-2/C4 perplexity 持平或优于同内存预算的 SVDQuant 与 BF16 rank-32 修正；尾部文档（worst 167 文档）误差降低 22%，说明收益不限于典型样本（预印本数据，未复现）。
  3. 优化方法带单调性论证：alternating sign peeling 每步在当前双线性目标下对一组符号取最优，单步 Frobenius 下降单调。
- 关闭条件：缺第三方复现；需对照 SVDQuant 官方实现的 kernel 级 wall-clock 数据。

## E2 · MPQ：把逐行 PTQ 看成离散码本上的后验推断

- 获取日期：2026-10-26
- 来源 URL：<https://arxiv.org/abs/2610.32127>
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖 LLM 权重后训练量化的求解器视角（GPTQ/LDLQ/BCD 统一化）；不覆盖激活量化与训练感知量化。
- 证据等级：A
- 可提炼要点：
  1. 观点：现有 PTQ 求解器在邻居块未参与前就把每个权重块锁定到单一 codeword，属「零温度、硬决策」极限，错过近优候选。
  2. Message-Passing Quantization 用 vector AMP 在块间保留软后验信息，输出阶段才做硬承诺，再以硬决策初始化做精化。
  3. 为量化箱提供「求解器谱系」新抽象，可并入既有 low-bit quantization 主题引用。
- 关闭条件：摘要级证据；需取原件核对与 GPTQ 的误差对比数值后再提炼定量结论。

## E3 · GS-MoE：免训练 MoE 压缩的双轴冗余削减

- 获取日期：2026-10-26
- 来源 URL：<https://arxiv.org/abs/2610.32009>
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖 MoE 专家权重的免训练压缩（共享子空间秩 + 专家中间宽度两轴）；不覆盖路由策略改动与专家再训练。
- 证据等级：A
- 可提炼要点：
  1. 两个压缩轴：组间低秩共享子空间捕捉跨专家共性并保留专家专有投影；Nyström 神经元压缩削减专家内中间宽度。
  2. 给出固定共享子空间下逐专家重构误差下降的闭式，用来引导专家分组；层间 rank/width 预算用免梯度层重要性分数分层分配。
  3. 与既有箱 moe-routing 的「路由/训练」层次互补，属「存储压缩」层次，合箱时建议引用不并块。
- 关闭条件：摘要级证据；需原件实验表（压缩率 vs 精度）才能进任何定量口径。

## E4 · 头维度与长上下文检索：宽头提高 retrieval head 占比

- 获取日期：2026-10-26
- 来源 URL：<https://arxiv.org/abs/2610.32213>
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖固定参数预算下多头注意力头维度分配对长上下文检索任务的影响；不覆盖推理 kernel 与位置编码方案比较。
- 证据等级：A
- 可提炼要点：
  1. 实证主结论：预训练 loss 与短上下文非检索任务几乎不受头维度影响；固定模型规模下，更宽的头顶高长上下文检索性能。
  2. 机制口径：宽头模型的 retrieval head 占比更高，即更多参数被用于检索行为。
  3. 对「长上下文架构设计」参考表是一手配置证据（头维度是可调旋钮而非纯规模函数）。
- 关闭条件：摘要未给具体数值表；需补原件中的规模/上下文长度边界后才能引用趋势结论。

## E5 · LazyFlash：前向 dense、反向 sparse 的长上下文微调注意力

- 获取日期：2026-10-26
- 来源 URL：<https://arxiv.org/abs/2610.31911>
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖长序列训练期注意力加速（反向按 query block 梯度范数跳过低贡献块）；不覆盖推理期稀疏注意力 kernel。
- 证据等级：A
- 可提炼要点：
  1. 关键设计取舍：前向保持完全 dense，训出的模型仍是标准 dense 模型，vLLM 等现有系统可原样服务——绕开稀疏训练模型的部署兼容问题。
  2. 反向用 gradient-aware block sparsification：按 query block 的注意力输出梯度范数排序，跳过对参数更新贡献可忽略的块。
  3. 观察依据「注意力训练由反向占主导」，可作为训练系统类正文的成本结构例子。
- 关闭条件：摘要级证据；需原件 wall-clock 加速比与精度损失数据（未复现）。

## E6 · Accordion：固定前缀层回环的弹性深度推理（MoE）

- 获取日期：2026-10-26
- 来源 URL：<https://arxiv.org/abs/2610.32492>
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖单一 MoE 模型支持五档推理预算的层回环训练与后训练保形；不覆盖非循环架构与逐档独立模型的方案对比成本分析。
- 证据等级：A
- 可提炼要点：
  1. 方法：fixed-prefix layer looping，每档预算走预定义执行路径，最小档保持不循环原模型；联合预训练每 micro-batch 采一档预算只优化其 NTP loss，不跨档一致性项。

  3. 与既有箱 looped-moe-diffusion 同一主题层次（推理预算弹性），合箱时作为追加证据块。
- 关闭条件：摘要未含各预算档精度曲线数值；需补原件或复现记录。
