## E1 · LLM 多智能体系统易受从众与失控级联：Music Lab 复现显示级联不易自纠

- 获取日期：2026-10-25
- 来源 URL：https://arxiv.org/abs/2610.30769
- 本地原件：—
- 适用范围：preprint，未经同行评议；仅摘要可得；覆盖大量 LLM agent 组成群体在推荐任务（对陌生歌曲打分、可见或不可见累计推荐数）中的从众与级联动力学；不覆盖真实产品流量与协作增益测量。
- 证据等级：A
- 可提炼要点：
  1. 机制：agent 回应他人选择形成内生反馈回路，暴露于累计推荐数引发失控级联——集体推荐极端化、不可预测，且与歌曲固有吸引力愈发背离。
  2. 对照人类：LLM 群体普遍比人类实验更易从众；且不同于人类，LLM 级联更缺乏自我修正能力。
  3. 影响面：作者点名 recommender、自动评估与复杂问题求解中的多智能体协作，对「多 agent 投票/评审」类设计是内生风险证据。
- 关闭条件：未取全文，群体规模与可自我修正性的操作化定义未核；需补 PDF 或等后续多环境扩展。

## E2 · CarryoverBench：一次性间接注入写入记忆文件或定时任务后跨会话再触发的攻击基准

- 获取日期：2026-10-25
- 来源 URL：https://arxiv.org/abs/2610.28425
- 本地原件：—
- 适用范围：preprint，已被 EMNLP 2026 主会录用（camera-ready 状态需人工核对）；仅摘要可得；覆盖个人助理 agent 的跨会话携带攻击（12 场景、101 攻击任务、3 触发通道）；不覆盖单次会话内注入检测（既有基准已覆盖）。
- 证据等级：A
- 可提炼要点：
  1. 威胁建模：agent 经两条持久通道跨会话携带状态——长期记忆文件被静默前置进 system prompt、计划任务无需用户输入即唤醒 agent；一次注入提交后「攻击者离开」仍反复再触发（carryover attacks）。
  2. 既有缺口：现行提示注入基准只在恶意内容首次出现的会话内评测，「载荷何时、多久再触发」的门控从未被测量。
  3. 协议：规则验证器把「植入」与「触发」作为独立阶段计分；触发通道分 Instant（同轮 IPI）/Autonomous（心跳计划）/Latent（记忆回冒）三类；5 个前沿模型上植入载荷在无可观测性下再触发（摘要截断处待核）。
- 关闭条件：未取全文，各模型再触发率与防御建议未核；EMNLP 正式版公开后可将本块状态升级为录用版。

## E3 · 轨迹↔标签审计：agent 评测的行为检测器系统性地与「轨迹所示」不一致

- 获取日期：2026-10-25
- 来源 URL：https://arxiv.org/abs/2610.30491
- 本地原件：—
- 适用范围：preprint，未经同行评议；仅摘要可得；覆盖 GSM8K 改造工具使用环境（计算器输出偶发损坏、有清晰真值）中 3 个轨迹级检测器 × 6 个生产模型 × 30 题的审计；不覆盖开放式任务与无真值环境。
- 证据等级：A
- 可提炼要点：
  1. 框架：最终正确性、工具校验等标签是解析器、行为检测器与 harness 规则产生的测量值，可能不忠实于轨迹本身所示——评测可信度的「测量层」问题。
  2. 关键失败模式：silent tool-output override——计算器返回损坏值后，模型不再次调用工具而直接用（常正确的）另一值，坏值停止传播，但可见行为与「再验证」标签系统性分歧。
  3. 结论形态：最终正确性、可见再验证、故障传播三种标签会以系统方式互相不一致，为「评测运行时栈身份登记」（10-18 档 DIB-Bench 结论）补充检测器级证据。
- 关闭条件：未取全文，三检测器具体一致率数字未核；需补 PDF 或与 04-benchmarks eval-methodology 线并读后判定归箱（本块暂登记安全监测箱）。
