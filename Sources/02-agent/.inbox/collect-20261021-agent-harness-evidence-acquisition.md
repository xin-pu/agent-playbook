# 投递：Agent harness 的证据获取与时序（工具输出检索化）

## E1 · 检索化工具输出导致的证据替换（evidence substitution）失效

- 获取日期：2026-10-21
- 来源 URL：https://arxiv.org/abs/2610.26836
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖「长工具输出落盘、按需检索」的 agent harness 设计对科学计算工具（USGS PHREEQC，报告可达 846.8k 字符）答题准确率的影响；仅 158 道执行验证的选择题与 GPT-5.x / Claude 4.6 系模型，不覆盖一般开放域任务。
- 证据等级：A
- 可提炼要点：
  1. 关键现象：agent 算对了值仍可能答错——通过 section index 检索报告而非上下文内联时，GPT-5.1 / GPT-5.2 准确率分别掉 11.3 / 7.9 分，而 Claude Opus 4.6 / Sonnet 4.6 无可检测损失。
  2. 复跑全部 11,007 次工具调用日志显示：模型算出目标键值的频率几乎不变，变化的是「从哪个证据作答」——检索模式下模型常跳过报告、引用自己更高精度的输出文件并舍入到相邻选项，作者命名为 evidence substitution。
  3. 干预对照：固定仿真结果、只改检索方式仍使 GPT-5.2 掉 9.4 分；显式点名权威输出可比朴素检索提高 6.3-7.9 分，「要求正确舍入」的提示无效；能放下的输出直接内联与点名等效。
  4. 可操作结论：harness 的上下文管理策略应按「准确性在哪里丢失」评估，而不是只看端到端准确率。
- 关闭条件：缺其他模型家族/工具类型的复制验证；出现第三方复现或作者扩展实验后可关。

## E2 · 调度器是隐藏检索器：异步执行时序塑造 search agent 的证据获取

- 获取日期：2026-10-21
- 来源 URL：https://arxiv.org/abs/2610.26310
- 本地原件：`Sources/02-agent/.inbox/originals/arxiv-2610.26310-hidden-retriever-scheduler.pdf`
- 适用范围：preprint，未经同行评议（NTU，v1 提交 2026-10-19）；覆盖 search agent 并行发起检索调用时，异步调度顺序对「最终拿到什么证据」的影响（Web agent 可靠性问题）；不覆盖同步执行系统或调度器优化的工程实现。
- 证据等级：A
- 可提炼要点：
  1. 机制观察：中间事实可能「来得及参与最终推理、却来不及指导后续搜索」——两条运行拿到相同原始文档与相同的搜索次数，仅因某实体名到达先后不同，一条取到关键日期并答对，另一条浪费搜索去识别实体。
  2. 论文把调度器称为「隐藏检索器」：执行时序与证据获取共同演化，到达的结果会触发新查询，因此工具调度的异步性本身就是检索行为的组成部分，而不仅是性能问题。
  3. 对评测的含义：比较不同 agent 系统时，若 harness 的并发/异步行为不同，控制变量应显式包含调度策略（与 `04` 域 harness 效应证据互补）。
- 关闭条件：需读全文补充实验设置（模型、任务集、量化幅度）；作者给出可复现协议或第三方引用复现后可关。
