## E1 · Hippo：海马体式选择性编码与重放做 training-free agent 自我进化

- 获取日期：2026-10-20
- 来源 URL：<https://arxiv.org/abs/2610.24453>
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖 LLM agent 经外部记忆积累经验、不动模型参数的自我改进；不覆盖参数更新类 RSI。
- 证据等级：A
- 可提炼要点：
  1. 负结果先行：不做固化（consolidation）的累积基线先升后降，最终反而低于无记忆基线——单一路径的成败都不可靠地映射经验价值（错误推理可能成功、正确策略可能执行失败）（摘要）。
  2. 关键机制：在同一任务的多次尝试间做对比，识别可复用的决策并修正其适用条件；受海马体选择性编码与重放启发的记忆框架 Hippo 按「诊断出短板」触发学习（摘要）。
- 关闭条件：对比式经验提取的触发频率与记忆污染风险需全文核对；「低于无记忆基线」的翻转点依赖任务序列，第三方复现后可关。

## E3 · HABIT-Bench：从纵向弱证据归纳用户习惯的记忆评测

- 获取日期：2026-10-20
- 来源 URL：<https://arxiv.org/abs/2610.24520>
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖长期交互中 agent 记忆系统对隐式用户信息的跨会话推断评测；不覆盖跨用户隐私与真实线上部署。
- 证据等级：A
- 可提炼要点：
  1. 设定：用户习惯由选择与行为透露，单次观测只给部分证据；仅保留历史交互不保证能推断并在后续请求中正确应用（摘要）。
  2. 构造：从任务型对话数据与受控习惯图合成用户历史，覆盖餐饮/金融/软件/旅行四域、数百会话，配四选一评测任务考察「弱证据归纳 + 适时应用」（摘要）。
- 关闭条件：习惯图的受控参数与合成历史规模需全文核对；基准尚无公开 leaderboard，被采用为对照前需复现。
