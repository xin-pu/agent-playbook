## E1 · Uni-Mem：端到端在线 RL 共训「记忆构建+检索」，需解开组比较混杂与稀疏反馈

- 获取日期：2026-10-25
- 来源 URL：https://arxiv.org/abs/2610.29671
- 本地原件：`Sources/02-agent/.inbox/originals/arxiv-2610.29671-uni-mem-agentic-memory-manager.pdf`
- 适用范围：preprint，未经同行评议；覆盖 LoCoMo 与 LongMemEval 上共享策略的长期记忆管理器（构建与检索两阶段共同学习）；不覆盖跨会话个性化与工具型记忆写入。
- 证据等级：A
- 可提炼要点：
  1. 缺口定位：已有学习型记忆方法或只优化构建，或「检索侧在线 RL + 构建侧离线监督」，两阶段无法互相适应。
  2. 难点刻画：直接用 GRPO 联合优化会面临组比较混杂（同一 rollout 组内两阶段变量互相污染）与长管理轨迹上的稀疏反馈。
  3. 方法：Stage-Decoupled GRPO——交替优化构建与检索、每组 rollout 内控制另一阶段的方差，得到阶段专属学习信号；Event-Wise Credit Assignment（ECA）把反馈定位到责任事件，再将事件级优势传播到其组成操作。
  4. 定量口径（预印本，未复现）：LoCoMo 与 LongMemEval 上超过对比中最强 RL 记忆基线（具体分值需从原件表读，本轮不引用）。
- 关闭条件：缺第三方复现；主表数字未从 PDF 抽出登记；补表格核对或作者更新后可关一半，会议版可全关。

## E2 · Raw-RAG 反证：稠密检索+重排原始历史的朴素基线在多数设置下排第一

- 获取日期：2026-10-25
- 来源 URL：https://arxiv.org/abs/2610.30755
- 本地原件：—
- 适用范围：preprint，未经同行评议；仅摘要可得；覆盖 LoCoMo、LongMemEval、MEME、MemoryAgentBench 四基准上「复杂 agentic 记忆 vs 朴素 RAG」对比；不覆盖需要记忆写入/整理的交互式学习任务。
- 证据等级：A
- 可提炼要点：
  1. 主张：对做变异、结构化组织、学习检索等复杂操作的 agentic 记忆系统，朴素 Raw-RAG（对原始历史做稠密检索+重排供读者模型）在 7 个基准×模型设置中 6 个排第一，超最强 agentic 记忆 0.13~5.53 分（预印本，未复现）。
  2. 机理：证据分析显示是「必要证据覆盖率更高」补偿了「利用率更低」；有用证据既含答案值也含推导所需的关联与依赖路径；即便完整访问变换后的记忆也未必占优（摘要截断处待核）。
  3. 用法边界：作为「复杂记忆架构必要性」的阴性证据块使用，结论限定在四个长对话基准族内。
- 关闭条件：未取全文（62 页含附录），各系统名单与重排器配置未核；需补 PDF 核对对比表后方可进提炼清单。

## E3 · 治理态腐蚀：记忆检索正确但「有效期状态」被改后模型误用记忆，跨 6 家供应商压力测试

- 获取日期：2026-10-25
- 来源 URL：https://arxiv.org/abs/2610.30698
- 本地原件：—
- 适用范围：preprint，未经同行评议；仅摘要可得；覆盖长驻 agent 记忆的治理故障（哪些留存记录可进入模型可见上下文）与「治理态腐蚀」测量协议；不覆盖内容级投毒与记忆删除性能。
- 证据等级：A
- 可提炼要点：
  1. 定义：governance-state corruption——存储内容与任务不变，仅由改变记录可见性的故障引发误用；区别于内容腐蚀，属记忆「控制平面」故障。
  2. 规模与协议：跨 6 家供应商，731 个基准锚定基座生成 2,080 对匹配故障；离线控制面检查中腐蚀在 96.25% 对上改变实际投影，oracle 支撑的强制恢复在 100% 对上还原。
  3. 下游读数（预印本，未复现）：确定性选出的非概率 LongMemEval/Memora 面板 300 匹配三元组解出 298；干净-腐蚀差为 LongMemEval 二元正确率 40.54pp（95% 基座簇区间 [30.32,50.71]）、Memora FAMA 重标度 30.60 点（[23.31,37.69]），两基准均观察到恢复。
  4. 关系：与 10-21 档 memory-contracts（契约式治理）构成「契约设计 ↔ 实证腐蚀测量」配对，合箱时建议互相引用。
- 关闭条件：未取全文，OAKS 原生选项实验（摘要截断处）与故障注入清单未核；需补 PDF 后判定是否升为治理线主证据。
