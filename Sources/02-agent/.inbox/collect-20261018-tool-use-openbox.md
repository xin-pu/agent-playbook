## E1 · 工具图记忆的反思：增益主要来自额外计算而非记忆内容本身

- 获取日期：2026-10-18
- 来源 URL：https://arxiv.org/abs/2610.21571
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖 9 个模型 × 2 个多轮工具使用基准上 tool graph memory 的消融对比；不覆盖非图结构的其他经验记忆形态。
- 证据等级：A
- 可提炼要点：
  1. 负面结果：把历史经验存为「工具转移图」再指导选择，在 9 模型 × 2 基准上很少显著优于基线；有增益时 LLM 调用开销翻倍以上。
  2. 机制拆解：记忆的引导常为错误引导，随机引导或无引导反而保留大部分增益——作者结论是该方法收益更像「额外计算」而非「记忆内容」的贡献。
  3. 对记忆主题箱的反向参照：与 agent-memory-state 中「经验信用」线形成对照组，提示经验复用类组件必须以消融+开销双口径评估。
- 关闭条件：缺跨更多基准（如 τ-bench 家族）的复核；预印本数据，未复现。

## E2 · 零样本工具选择的 transfer-validity gap：语义相关不等于功能可用

- 获取日期：2026-10-18
- 来源 URL：https://arxiv.org/abs/2610.20388
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖未见领域/执行上下文下的零样本工具选择，提出「相关性→有效性」的渐进验证框架；不覆盖运行时工具编排与失败恢复全链路。
- 证据等级：A
- 可提炼要点：
  1. 识别出 transfer-validity gap：语义相关度排序选出的工具在新上下文里可能功能不兼容或语境不适用——把工具检索的评价口径从 ranking 质量推向可用性判定。
  2. 方法路径：用 endpoint-grounded 的功能验证 + 上下文验证补语义相关性，二者渐进串联；对 function calling 评测设计的启示是「选对工具」与「调得通」是两个可分离的错误层。
- 关闭条件：未取原件核对定量结果；需要与既有 relevance-ranking 基线（embedding 检索）在同基准上第三方对比后方可关。

## E3 · Davinci-Tool：以「可恢复状态+执行轨迹+验证器」为监督基座扩工具使用训练数据

- 获取日期：2026-10-18
- 来源 URL：https://arxiv.org/abs/2610.16867
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖 30B 工具使用模型与其执行接地数据集 Davinci-ToolData 的构造口径；不覆盖与更大模型的能力对比结论。
- 证据等级：A
- 可提炼要点：
  1. 数据口径：把 restorable states、execution traces、outcomes、verifiers 作为统一监督基座，使「环境覆盖」与「结果验证」同步扩展——单扩轨迹数量或单扩验证器都不足，是新环境引入新状态/规则/依赖时必须连带更新成功判据。
  2. 与 04 域呼应：其 verifier-as-dataset-part 的思路与本轮 eval-methodology 候选块（oracle 完整性审计、基准可信度）同源，合箱时建议交叉引用。
- 关闭条件：本轮受原件配额限制未下载 PDF；下一轮以 `https://arxiv.org/pdf/2610.16867` 补原件并核对训练配比结论后方可关。
