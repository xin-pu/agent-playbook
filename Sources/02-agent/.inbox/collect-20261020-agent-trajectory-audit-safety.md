## E1 · ORA「一像素推理」：单条真源限定句翻转 agent 结论

- 获取日期：2026-10-20
- 来源 URL：<https://arxiv.org/abs/2610.24873>
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖面向 agent 信念的推断关系攻击（定位证据→结论间的隐含 warrant 并单句干预）；实验域为生物医学推断与漏洞检测。
- 证据等级：A
- 可提炼要点：
  1. 攻击面新刻画：不是伪造证据而是「限定」一条真实来源与结论间的隐含保证；18 个模型上 best-of-10 攻击平均翻转初判正确率为闭源 54.9%、开源 80.0%，且无需受害者反馈可迁移（预印本数据，未复现）。
  2. 对照组支持「定位」与「限定」两个成分各自的必要性，说明该面无法靠更强检索或拒答直接覆盖（摘要）。
- 关闭条件：翻转率对攻击句检索/生成预算的敏感性需全文；防御建议是否给出原型未核，需补丁式复现后可关。

## E2 · Write once, check many：策略无关 ledger 复用做轨迹事后合规审计

- 获取日期：2026-10-20
- 来源 URL：<https://arxiv.org/abs/2610.24483>
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖「每条轨迹记录一次、多策略复用」的 agent 合规审计框架；不覆盖在线阻断（仅事后审计）。
- 证据等级：A
- 可提炼要点：
  1. 结构：writer 模型把轨迹转成 policy-independent 的动作-结果叙述 ledger；reader 仅对 ledger 校验未知策略，不回读原轨迹（摘要）。
  2. 效率结果：900 条轨迹（SHADE-Arena、τ-bench、τ²-bench）上 12B reader 读叙述 ledger 的 AUC 持平甚至高于同模型读完整轨迹（预印本数据，未复现）。
- 关闭条件：ledger 遗漏动作细节导致的漏检率（false negative 面）需全文核对；跨策略族复用规模有限，需扩展复现后可关。

## E3 · 弱用户才是常态：强模拟用户训出的 tool agent 对弱用户无解，StaGPO 转向状态显式化

- 获取日期：2026-10-20
- 来源 URL：<https://arxiv.org/abs/2610.24294>
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖工具调用 agent 在模拟弱用户（遮蔽回复句）下的训练/评测错配；基准为 tau2-bench 与 ToolWOZ。
- 证据等级：A
- 可提炼要点：
  1. 交叉评测负结果：弱用户使所有策略成功率下降；以弱用户训练（固定遮蔽、混合、curriculum 三种课程）均不优于强用户训练策略，仅让 agent「多提问」的 prompting 也无效（预印本数据，未复现）。
  2. 作者方案 StaGPO：把任务信息状态显式写入 agent 输出再优化（State-Grouped Policy Optimization），机制细节以全文为准（摘要截断处）。
- 关闭条件：StaGPO 相对强训基线的增益数值未在摘要给出；tau2/ToolWOZ 之外的用户噪声形态未验证，需复现后可关。
