# 投递：Agent 长期记忆：写契约自进化与潜势记忆的作用域修正

## E1 · BetaMem：六层可追溯长期记忆与失败驱动的递归自我改进

- 获取日期：2026-10-21
- 来源 URL：https://arxiv.org/abs/2610.26554
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖具身/长时程 agent 的长期记忆构建（以 Qwen3.5-9B 做记忆生成模型），评测协议为 M3-Bench-robot、LoCoMo、OpenEQA EM-EQA、EgoLifeQA、EMem-Bench；不覆盖闭源大模型直接做记忆管理的场景，数值仅在「所列方法与其各自评测协议」下可比。
- 证据等级：A
- 可提炼要点：
  1. 架构：工作、空间、实体、情景、经验、程序六层联动记忆；「双层写契约」约束记忆操作的可执行性与内容溯源（须有原始观测支持）。
  2. 训练配方：SFT 学会合规的记忆操作，RL 以重复采样 + 教师对原始观测的验证来奖励完整准确记录、惩罚遗漏/扭曲/无依据内容；另有沿记忆操作因果链诊断、以独立回放门控局部规则修复的失败驱动递归自我改进。
  3. 定量（作者自评，未复现）：整体得分 M3-Bench-robot 48.08%、LoCoMo 92.08%、OpenEQA EM-EQA 72.6%、EgoLifeQA 62.4%，为所列记忆方法最高；记忆生成训练使写契约通过率从 50.9% 升至 86.2%，每个存储动作的输出 token 减少 47.3%。
  4. 把存储/更新/检索/遗忘框成原子工具在存储与读取预算下的成本-效用分配问题，呼应 `02-agent` 既有记忆箱的预算视角。
- 关闭条件：缺第三方复现与同协议对照（其基线选择由作者给定）；独立评测或开源权重可验证后可关。

## E2 · ScopeMem：潜势记忆收益主要来自动作修正，需限定修正作用域

- 获取日期：2026-10-21
- 来源 URL：https://arxiv.org/abs/2610.26503
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖 GUI agent 的潜势记忆（prefix 向量补充历史）方法学分析，实验在 AndroidControl、GUI-Odyssey 与零样本 AITW 上用冻结 Qwen3-VL-8B；不覆盖非冻结主干与自回归记忆检索类方法。
- 证据等级：A
- 可提炼要点：
  1. 反直觉发现：潜势记忆带来的收益主要不是「编码了历史」，而是 prefix 学会了修改模型默认动作；在受控消融集上，逐步交叉熵训练会破坏 8-13% 原本正确的决策，且被总体准确率掩盖。
  2. 方法：ScopeMem 的编码器以模型初始答案为条件生成 prefix，训练目标为「改错同时保对」的限定作用域修正，把被破坏的正确决策占比降到 5.6%，同时修复更多错误。
  3. 结果口径：作者称在三个数据集上超过所有评测的 prompting 与潜势记忆基线，使冻结的 Qwen3-VL-8B 达到或超过 GUI 特化 agent 与 Qwen3-VL-32B（预印本数据，未复现）。
  4. 方法论警示：评估记忆类方法应拆解「修复错误数 / 破坏正确数」两个方向，单看整体 accuracy 会隐藏损失——可与 `04-benchmarks` 的评测完整性证据互相引用。
- 关闭条件：缺独立复现与在其他主干模型上的作用域修正验证；出现第三方复现后可关。
