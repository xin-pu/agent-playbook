## E1 · MemComposer：用 GRPO 系 RL 训练「记忆组装器」，检索语义相似不等于记忆有用

- 获取日期：2026-10-18
- 来源 URL：https://arxiv.org/abs/2610.21091
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖 agent 外部记忆的选择/数量/排序策略学习与端到端任务反馈优化；不覆盖具体部署环境的工程开销与延迟数据。
- 证据等级：A
- 可提炼要点：
  1. 提出记忆组装器 MemComposer：联合考察当前 query 与候选记忆，决定纳入哪些、选几条、按什么顺序呈现；把「记忆组装」显式建模为可学习策略而非固定检索管线。
  2. 训练用 ExPO（GRPO 系框架）：对「组装后的完整记忆上下文」做完整 agent 交互评估，以任务成败反馈优化组装策略——记忆质量以下游任务成功率定标，不以检索相似度定标。
  3. 核心论断：语义相似度不保证记忆有用，下游性能取决于选择与呈现方式。与首轮已登记结论（经验信用、显式世界模型）互补，方向从「存什么」推进到「怎么用」。
- 关闭条件：缺第三方复现与跨基准消融；作者团队放出代码仓库或会议版录用后可部分关闭。

## E2 · Cortex：把上下文增益固化为参数记忆，统一「编辑—技能—行为」三种写入

- 获取日期：2026-10-18
- 来源 URL：https://arxiv.org/abs/2610.20399
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖 4B~120B dense 模型上的记忆固化（context 去除后保留增益）评测与低秩/结构化合并方法；不覆盖 agent 运行时多轮记忆的在线管理。
- 证据等级：A
- 可提炼要点：
  1. 把「记忆固化」形式化为：将上下文带来的性能增益内化进参数、同时保留非目标能力；在该目标下把上下文知识编辑、技能学习、行为引导统一为同一类问题——为记忆写入给出统一目标函数视角。
  2. 方法要素：生成 prospective queries 预判上下文未来用法，再把 context-conditioned 输出蒸馏进可合并的低秩/结构 FFN 更新；五任务族测试床分别测单次、批量、顺序更新下的固化与保持。
  3. 与既有箱线索的关系：agent-memory-state 首轮记的是「外部记忆与经验信用」，本文给出「外部→参数」的内化路径，属同一主题的互补分支，可并箱登记。
- 关闭条件：定量结论（4B~120B 上的固化/保持幅度）仅来自摘要，未取原件核对；需下载 PDF 复核或等第三方复现后方可关。
