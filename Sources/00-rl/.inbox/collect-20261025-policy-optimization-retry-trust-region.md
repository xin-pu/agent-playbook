## E1 · ReAPO：把「带失败上下文的串行重试」纳入 Stochastic Shortest Paths 信用分配

- 获取日期：2026-10-25
- 来源 URL：https://arxiv.org/abs/2610.28770
- 本地原件：`Sources/00-rl/.inbox/originals/arxiv-2610.28770-reapo-retry-aware-policy-optimization.pdf`
- 适用范围：preprint，未经同行评议；覆盖 Qwen3/OLMo-2 0.6B~4B 在 8 个数学与科学推理基准上的 RLVR 组采样训练；不覆盖非可验证奖励域与在线部署。
- 证据等级：A
- 可提炼要点：
  1. 问题定位：GRPO 依赖策略随机性探索，容易反复采到相似的失败策略；把前次错误解放入上下文可引导探索，但引入「每次重试如何计功」的问题。
  2. 方法：在合理简化假设下把该场景看成经典 Stochastic Shortest Paths（最小化到终止状态——验证通过的回复——的期望累计代价），导出对 GRPO 的简单修正 ReAPO：给失败轨迹追加生成量、只强化成功的重试而不奖励先前失败，并逐次分配有理论依据的信用。
  3. 定量口径（预印本，未复现）：相对 GRPO 提升首次尝试准确率；在 Qwen3-0.6B 上超过组大小翻倍或训练步数翻倍的 GRPO，分别省 39% 与 31% 的生成 token 即达到其峰值精度。
  4. 消融显示串行采样与重试感知信用两者各自都有贡献；代码开源于 github.com/Nghi-Dao/ReAPO。
- 关闭条件：缺第三方复现与更大模型（>4B）验证；作者会议版或公开复现后可关。

## E2 · EPIC：token 级裁剪忽略「前缀由策略自己生成」，改用精确 KL 前缀重要性比

- 获取日期：2026-10-25
- 来源 URL：https://arxiv.org/abs/2610.29999
- 本地原件：—
- 适用范围：preprint，未经同行评议；摘要与首页可得，正文未取全文；覆盖 PPO 式裁剪在长回答、离策略训练下的信任域修正；不覆盖具体实验表。
- 证据等级：A
- 可提炼要点：
  1. 论断：标准 token 级裁剪只度量当前 token 的条件概率变化，而前缀上下文本身就是策略生成的；这一失配在长回答与离策略训练下尤其严重。
  2. 推导：把自回归生成重写成有限时域 MDP，在行为策略采样下导出性能差恒等式；换测结果显示每步策略改进项的精确重要性权重是「已生成前缀的累积似然比」。
  3. 方法：从 TRPO 单调改进原则出发构造前缀信任域（Exact-KL Prefix Importance-Ratio Clipping）；代码见 github.com/LiChengxi666/EPIC（27 页）。
  4. 与既有口径关系：与 00-rl 投递 10-18 档 2610.18738（token 级重要性采样 + proximal KL）同属「修正 GRPO/PPO 度量口径」线，合箱时建议相邻排布。
- 关闭条件：本轮仅取摘要，性能数字与消融未核；需补下 PDF 核对实验节后方可进提炼清单。

## E3 · Projected Distillation：把「在策略性」当连续谱，最小编辑失败尝试作为学习目标

- 获取日期：2026-10-25
- 来源 URL：https://arxiv.org/abs/2610.27467
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖 Qwen3-8B、OLMo-2-7B 在数学、代码、科学、工具使用 5 个域的后训练对比；不覆盖多模态与超大模型。
- 证据等级：A
- 可提炼要点：
  1. 动机：难题上全错时 on-policy RL 无学习信号；on-policy 蒸馏在早期出错后监督就建立在含错误的后缀上；直接改用标准答案（离策略目标）会侵蚀既有能力。
  2. 方法：投影蒸馏（projected distillation）用对比更新把学生失败尝试「最小编辑」成正确目标，并随学生进化刷新目标，在全部尝试失败时仍近似 on-policy。
  3. 理论：学习 regret 随编辑规模增长——最小编辑下随 horizon 线性（类 DAgger），整解替换下二次（类行为克隆）。
  4. 定量口径（预印本，未复现）：在 9 格中 8 格优于 GRPO 与 OPD、7 格优于 SPOT 与 SODA 拿下专精-保持前沿最优面积；把最小编辑换成学生无关的金答案后保持度从 0.916 掉到 0.744。
- 关闭条件：缺第三方复现；理论部分需人工核证明假设；会议版录用或复现报告可关。
