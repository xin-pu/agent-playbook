## E1 · 无监督 RLVR 自强化坍缩的集体动力学解释

- 获取日期：2026-10-29
- 来源 URL：<https://arxiv.org/abs/2610.37553>
- 本地原件：`Sources/00-rl/.inbox/originals/arxiv-2610.37553-rlvr-self-reinforcement-collapse.pdf`
- 适用范围：preprint，未经同行评议；小 Transformer 上的 label-free RLVR（自多数投票奖励）与均场理论模型；覆盖「自评估奖励升高而准确率下降」的坍缩相变机理；不覆盖有监督奖励的常规 RLVR 全流程与前沿规模模型。
- 证据等级：A
- 可提炼要点：
  1. 坍缩只在大题量训练时出现：题目共享参数时，群体平均斜率 ⟨F′⟩>0 会放大共享扰动；临界题量 Nc ≃ ln(1/δ)/(λ²G)（λ 为共享耦合强度，δ 为噪声种子）。
  2. 每题锐化以 1/N 减速，而共享模态以 ∝λ² 增长、与 N 无关，两者竞速决定相变；模拟确认 Nc ∝ λ⁻²（对数修正）与批次大小仅对数依赖。
  3. 实验结论：在小 Transformer 的 label-free RL 中移除共享方向可完全防止坍缩；初始置信度高的模型不坍缩。
  4. kernel 版理论识别出两个保护项：锐化的泛化耦合与边际熵 bonus，可稳定均匀集体模态。
  5. 与既有箱关系：与本域 `rlvr-rollout-diversity-efficiency`、`preference-optimization-collapse` 两条线同题，合箱时互引不复制。
- 关闭条件：理论基于可解多题模型与小规模验证；缺前沿规模模型上的定量复现。补第三方复现或在同类 self-reward 设置中的消融证据后可关。

## E2 · AdaRoll-GRPO：用 Bayes-Adaptive MDP 学习难度感知的 rollout 分配

- 获取日期：2026-10-29
- 来源 URL：<https://arxiv.org/abs/2610.37429>
- 本地原件：`Sources/00-rl/.inbox/originals/arxiv-2610.37429-grpo-rollout-allocation-bamadp.pdf`
- 适用范围：preprint，未经同行评议；GRPO 训练期的 rollout 预算分配（与标准 GRPO 同总额度）；覆盖多个推理数据集与 LLM 架构上的一致性提升；不覆盖在线服务推理调度与跨模型规模的最优额度标定。
- 证据等级：A
- 可提炼要点：
  1. 动机口径：全对/全错的题奖励相同→优势为零→无学习信号；把额度从信号充分的中等偏易题转移到需要探索的题，可提高参与更新的问题占比。
  2. 方法：将分配建模为序贯决策，用 Bayes-Adaptive MDP 学分配策略；策略离线求得，训练期直接使用，不引入额外在线优化开销。
  3. 结果：固定总额度下多数据集、多架构一致改善 GRPO 训练表现（定量数值见原文表格，未在摘要给出）。
  4. 与 `2610.36807`（难题 rollout 信号，2026-10-28 投递 E1）构成同一条「rollout 预算」证据线，合箱互引。
- 关闭条件：预印本定量结论未复现；作者未公开代码链接（公开资料未给），需代码发布或会议版录用后关。

## E3 · EnvSched：环境感知调度让 agentic RL 在有限 rollout 预算下提效

- 获取日期：2026-10-29
- 来源 URL：<https://arxiv.org/abs/2610.37609>
- 本地原件：`Sources/00-rl/.inbox/originals/arxiv-2610.37609-envsched-agentic-rl-scheduling.pdf`
- 适用范围：preprint，未经同行评议；语言 agent 的可执行环境批量调度（工具/状态/验证器为环境属性）；覆盖 Qwen3-8B 在 BFCL-v3、τ-Bench、ACEBench-Agent 的训练期吞吐；不覆盖视觉/具身环境与闭源前沿模型对齐训练。
- 证据等级：A
- 可提炼要点：
  1. 双建模：exploitation 优先奖励差异信息量高的任务，coverage 摊开欠观测环境与交互模式；环境-任务对组织为双关系图（环境内语义/工具/验证器边 + 跨环境执行/奖励拓扑边），沿边传播历史 rollout 统计预测任务内奖励方差。
  2. 结果：Qwen3-8B 上 40 步平均 48.81（三基准），超过随机任务选择 120 步能达到的最高分；同预算下跨模型尺寸改善下游表现。
  3. 无需额外 pilot rollouts；环境配额与相似度惩罚抑制批次集中与冗余。
  4. 代码已公开（见 PDF 首页 Code 行 `github.com/Hhankyangg/envsched`，可复核口径）。
- 关闭条件：单组实验、模型止步 8B 档；需第三方复现或更大规模验证；代码仓库持续维护情况可在后续巡检中确认。
