# 投递：奖励模型分数的跨提示可比性（2026-10-24 daily）

## E1 · 成对评测测不到「跨提示共享分量」的审计方法

- 获取日期：2026-10-24
- 来源 URL：https://arxiv.org/abs/2610.31090
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖 reward model 分数在偏好优化、过滤与排序中被跨提示池化时的可比性审计；不覆盖成对评测本身的排序有效性。
- 证据等级：A
- 可提炼要点：
  1. 盲区刻画：成对评测只比较同一提示下的两个回答，任何「该提示所有回答共享的分数分量」会相消、完全未被测试，而下游用法（pooling across prompts）恰恰依赖这个分量可比。
  2. 方法：以人类评分为参照做审计——between-prompt 方差占比、sibling-rating 回归与提示替换三个构件。
  3. 应用范围：摘要称审计应用于 eighteen released（原文截断，推测为 released reward models）个公开奖励模型；具体名单与结论需读全文核实。
- 关闭条件：摘要截断导致样本数与主要发现未核；需下载 PDF 核对被审计模型清单与跨提示方差结论。

## E2 · 记忆增强回答并不总被用户偏好（Memory-Aware Reward Modeling）

- 获取日期：2026-10-24
- 来源 URL：https://arxiv.org/abs/2610.31272
- 本地原件：—
- 适用范围：preprint，未经同行评议；覆盖跨会话记忆个性化场景下的人类偏好数据采集与奖励建模；不覆盖非 ChatGPT 查询来源与更长记忆存储规模。
- 证据等级：A
- 可提炼要点：
  1. 数据：约 1,000 条成对偏好判断、87 名参与者，使用其本人 ChatGPT 查询与个人记忆构造「带记忆 vs 不带记忆」对照。
  2. 核心发现：带记忆的回答相对不带记忆的回答并非一致被偏好，部分情形用户反而不喜欢——「知道更多」不等于「答得更好」，现有记忆能力评测未直接建立记忆使用对用户收益的因果。
  3. 对 reward model 线的新问题：偏好标签本身要建模「记忆使用」这一维度，而非只评最终回答质量。
- 关闭条件：被截断摘要未给出建模方法与准确率增益；需读全文核对实验设定（人群构成、记忆长度分布）后关。
