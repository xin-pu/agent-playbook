# 投递：Trace2World——从真实交互轨迹重建 GUI Agent 训练世界（2026-10-23 daily）

## E1 · 行为重建与实现分离的可验证 app world 合成

- 获取日期：2026-10-23
- 来源 URL：https://arxiv.org/abs/2610.30792
- 本地原件：—（PDF 约 45MB，单次抓取 120s 超时，按规则失败一次即跳过；仅摘要登记）
- 适用范围：preprint，未经同行评议；覆盖 GUI agent RL 训练环境的合成与验证（Android 类 app 工作流）；不覆盖 web agent 与桌面环境。
- 证据等级：A
- 可提炼要点：
  1. 问题设定：把部分轨迹直接「行为推断+编码」成可运行 mock 会产生错误的状态迁移；Trace2World 将全局行为重建与实现解耦——先把轨迹调和为带源码链接的共享 app 模型，再编译为可执行环境。
  2. 验证机制：对源工作流做独立回放定位不匹配、限定范围修复；验证通过的世界再做学习者自适应的任务/环境增广（限源支持行为内）。
  3. 定量口径（预印本数据，未复现）：1,570 条轨迹构建 50 个环境；10 个 app 的 200 条工作流端到端复现率 91.1%，对比最强 matched task-local 基线 59.8%；源接地验证使模拟训练增益在真机上保留 94.0%。
  4. 与 20261022-agentic-rl-harness-env 投递（2610.29426 BIRD 状态环境）同属「agentic RL 环境保真度」主题，合箱时建议并箱或互引。
